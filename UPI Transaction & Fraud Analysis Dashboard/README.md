# UPI Transaction & Fraud Analysis Dashboard

## Overview
An end-to-end interactive Power BI dashboard developed to analyze transaction patterns, payment application market share, and fraud risk factors. This project transforms raw transaction data into actionable insights for financial monitoring.

## 🚀 Key Technical Skills
*   **Data Modeling:** Implemented a **Star Schema** with robust relationships between Users, Merchants, and Transactions.
*   **ETL Processes:** Performed data cleaning and transformation in Power Query, including merging datasets and optimizing data types.
*   **DAX Proficiency:** Developed complex measures for KPIs, including Total Volume, Transaction Frequency, and Fraud detection segmentation.
*   **UI/UX Design:** Crafted a multi-page dashboard featuring a sleek, professional aesthetic and interactive slicers for regional drill-down analysis.

## 📊 Dashboard Highlights
### Executive Overview
*   **KPI Banner:** Real-time tracking of Total Volume (₹), Total Transactions, and Fraud Cases.
*   **Market Share:** Interactive donut chart visualizing the dominance of major UPI apps (GPay, PhonePe, etc.).
*   **Risk Analysis:** Clustered bar chart identifying high-risk user age demographics.

### Transaction Analytics
*   **Trend Analysis:** Month-over-month volume tracking to identify spending spikes.
*   **Merchant Insights:** Breakdown of transaction volume by merchant category.
*   **Top-N Analysis:** Granular performance tracking of top 10 merchants using filtered table visuals.
