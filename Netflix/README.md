# Netflix Content Strategy Analysis - Power BI

## 📌 Project Overview
A self-directed, end-to-end Power BI application designed to analyze Netflix's global content library. This interactive dashboard explores the distribution of movies versus TV shows, geographical content production, genre popularity, and top-performing directors and actors.

## 🛠️ Tech Stack & Skills Demonstrated

Tool: Power BI Desktop

Data Processing (ETL): Power Query, M-Code

Calculations: DAX (Data Analysis Expressions)

Data Modeling: Star Schema, One-to-Many Relationships, Bidirectional Cross-Filtering

Design: Custom UI/UX, Dark-Mode Aesthetic, Tile Slicers

Advanced Features: Natural Language Processing (NLP) Q&A Visual, Decomposition Tree

## 📊 Dashboard Pages

Executive Overview: A geographical and high-level distribution of Netflix's entire catalog, featuring custom donut charts, filled maps, and dynamic timeline slicers to track content addition over time.

Cast & Directors: A relational data deep-dive highlighting the platform's top contributors. Built using custom dimension tables (Dim_Cast, Dim_Genres) to break down flat-file constraints and allow for accurate, independent metric calculations.

AI Insights: Integrates Power BI's Decomposition Tree to dynamically explore content breakdowns by type, rating, and genre, alongside a Natural Language Q&A engine for user-driven querying.
