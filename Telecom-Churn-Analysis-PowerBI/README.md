# Telecom Customer Churn Analysis - Power BI

## 🚀 Project Overview
This project focuses on analyzing customer churn for a telecom company to identify key drivers of customer attrition. By leveraging **Power BI**, I transformed raw data into an actionable dashboard that empowers stakeholders to take proactive measures to retain customers.

This project was completed as part of my **Power BI Internship at Codveda Technology**, achieving **Level 3 proficiency**.

## 🛠 Tools & Technologies
* **Power BI Desktop:** Data Modeling, DAX, Visualizations.
* **DAX (Data Analysis Expressions):** Advanced logic for metrics and dynamic assessments.
* **Row-Level Security (RLS):** Implemented for regional data access control.
* **Power Automate:** Integrated for automated data-driven alerts.

## 🔑 Key Features
* **Advanced DAX Measures:** Utilized `VAR` and `SWITCH` functions to create a "Dynamic Risk Assessor" for business health monitoring.
* **Leaderboard Metrics:** Implemented `RANKX` to identify high-priority states requiring intervention.
* **Security Implementation:** Configured Row-Level Security (RLS) to restrict data access based on user roles (e.g., Regional Managers).
* **Conditional Formatting:** Applied dynamic coloring to highlight problem areas where service calls exceed the churn threshold.
* **Interactive Tooltips:** Custom report-page tooltips provide deep-dive insights without cluttering the main dashboard.
